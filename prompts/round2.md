# 第二轮提示词

```text
第二轮迭代。不要执行终端、shell 或沙箱命令，不要扫描目录；只直接编辑现有 HTML/CSS/JS 文件，并在写入前请求授权。

保持第一轮功能不变，新增：
1. 每个餐厅详情增加“去这里”按钮。点击后调用高德 REST 步行路线接口 /v3/direction/walking，origin 为当前定位，destination 为餐厅，key 从 window.APP_CONFIG.amapKey 读取。展示预计距离、步行时间和简短路线描述。接口失败或 Mock 模式时按直线距离估算路线，仍展示“约 X 米、步行约 Y 分钟”和路线描述。
2. 确保每张餐厅卡片都有结合距离、价格、评分、口味生成的推荐理由。
3. 增加价格筛选：全部、平价(<30)、中档(30-80)、高档(>80)。
4. 增加口味筛选：全部、川菜、粤菜、日料、西餐、小吃、奶茶。
5. 价格、口味、关键词、排序必须可组合过滤，并同步更新结果数量和地图标记。
6. 路线详情可展开和收起，移动端布局正常；不修改安全配置，不把 Key 写入提交文件。

完成后只汇报修改文件和验收要点。
```
